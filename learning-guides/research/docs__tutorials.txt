Frequently asked questions

Courses vs the docs — what's the difference?
Courses are guided, build-along walkthroughs; the docs are the reference you look things up in. Each course links back to the relevant docs, and vice-versa.
Do I need to do them in order?
Start with a guided track (Web, Desktop, or Mobile) if you are new. The focused tutorials are standalone — pick whichever topic you need.

Something wrong, unclear, or missing on this page?
